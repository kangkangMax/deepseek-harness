# @deepseek-ai/dsh-experimental-client-ui-worktree-console

[English](README.md) | 中文

## 概述

在设置中按可折叠的仓库分组管理工作树。在输入框准备隔离会话，并在会话模式旁查看当前分支。目录详情提供复制和可选的桌面打开操作。本包不贡献任何模型上下文。

## 使用此包

由 `@deepseek-ai/dsh-experimental-worktree-console-bundle` 挂载，不单独挂载。它注册四项贡献。

| 席位 | 行为 |
| --- | --- |
| `settings.section`，id `worktree-console` | 设置面板左侧的「工作树」导航项，点开即管理页。 |
| `conversation.input.left`，id `worktree` | composer 复选框 —— 空白会话显示可勾选的控件，勾选后旁边出现基点分支选择器。宿主拒绝的那次 run 结束后，这一行改为报告原因：意图已被消费掉，再给一个开关也武装不出任何东西。已经进入工作树的会话在这里没有可决定的事，因此整行不渲染。 |
| `conversation.session.header.actions`，id `worktree-context` | 会话模式后的当前分支。悬停查看完整名称、检出目录和目录操作。 |
| `shell.overlay`，id `worktree-console.notice` | 设置页关闭后仍可见的操作结果。 |

管理页与输入框控件读取 `worktrees` Remote。基点选择器从 `state.request` 恢复宿主接受的意图，且只在宿主接受选择后更新显示。本地和远程分支使用完整引用名，确保同名分支可区分。

删除始终打开确认对话框。工作树有关联会话时，对话框显示数量，并要求单独勾选确认归档，聊天记录会保留。丢弃文件改动需要另行确认。取消后两项确认都会重置。如果读取所显示的列表后又有会话关联到工作树，宿主会拒绝删除。

基点选择器随勾选一起出现，而不是提前出现。未勾选时没有任何东西需要限定；一个等在旁边的基点控件会被读成「必须先设对」的前置设置。这也让从未武装过的会话（也就是大多数会话）根本不去读分支列表。

仓库分支超过六个时，卡片才带搜索框。少于这个数，扁平列表扫一眼比搜索更快，三个分支上的输入框是永远赚不回空间的输入框；多于这个数，二十个分支根本没法扫。搜索沿用全app 每一个菜单查询都在用的 `rankByName` 排序，所以分支的匹配方式和斜杠命令一致；输入框保持焦点，↑/↓移动高亮、Enter 或 Tab 落定。`当前 HEAD` 那一行始终钉在输入框上方：HEAD 不是分支 —— 它在用户发送的那一刻才解析 —— 所以任何查询都不能藏掉「不指定基点」这一行。

<a id="understand-the-implementation"></a>
## 理解实现

管理页独占设置面板的一个导航项，因此不与任何插件的配置页混在一起。

每个仓库分组可独立展开或折叠工作树表格，进入页面时默认展开。折叠后保留分组标题、数量和独立的「清理失效记录」操作。清理仅移除检出目录已不存在的 Git 登记，不删除仍存在的目录。刷新保留仍存在分组的展开状态。刷新按钮与页面标题及说明的组合垂直居中。

表格将剩余宽度分给分支及次级目录文字。点击行内操作按钮以外的区域可打开紧凑详情；在行上按 Enter 或空格，或激活分支按钮，也会打开详情。弹窗仅显示一次完整分支名，同时展示目录、来源、已忽略文件数和提交，并提供「复制路径」及可选的「打开目录」操作。窄面板隐藏表格中的来源列，但详情仍显示来源。删除确认将目录、删除影响、会话归档确认和文件丢失警告分区展示；窄面板中底部操作可以换行。

长分支名在表格中保留首尾。详情完整显示分支名和路径，不做截断。

容器查询在设置面板变窄时将行内容堆叠。仓库名和标题可换行。读取失败保留已加载的行并在原位显示错误；操作结果由 shell Toast 显示。

会话页头仅在模式旁显示分支，长名称在不超过 160px 的控件内截断。唯一的悬浮卡片展示完整分支名和检出目录，以及复制和可选的桌面打开操作。点击或触屏轻触分支不会打开弹窗，也不会固定卡片。键盘聚焦保留共享卡片的预览行为。输入框底部不重复显示分支。

面向 Remote 的函数单独成模块而非写在组件里。这样浏览器 spec 可以对着一个字面 face 运行，而不必 import 只在构建后才存在的 Remote 生成物。

没有任何组件替宿主做决定。页面按 `state` 报告的原文渲染武装标志与已进入的检出；复选框与分支行在宿主回答之前都不渲染 —— 因此挂载不会在「已武装/未武装」之间闪，它们也都不会报告一个宿主从未创建过的检出。

输入框复选框与页头分支在一次运行结束时重读，以报告被拒绝的启用原因，并在创建工作树后更新显示的分支和目录。

<a id="model-experience"></a>
## 模型体验

### Composer 工作树复选框

#### 模型可见内容

本包不贡献任何内容。它在浏览器里渲染控件；真正的模型可见变化是宿主在武装的 step 运行时做出的工作目录切换。

#### Token 影响

没有。开关、徽章与管理表都不会进入模型请求。

#### KV Cache 影响

没有。不产生模型上下文，因此本包不会改变任何缓存前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **复选框只服务空白会话** —— 宿主也会拒绝启用已经开始过轮次的会话。
- **会话的读取在两轮之间刷新，而不是轮内** —— 分支、目录与武装状态在一次 run 结束时重读一次，因此 run 中途切换的检出会一直保留旧名字，直到这一轮结束。
- **已忽略文件与改动分开报告** —— 页面显示已忽略文件数，删除前必须确认丢弃这些文件。
